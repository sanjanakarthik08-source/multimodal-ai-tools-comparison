## 📌 Overview

**Multimodal AI Tools Comparison** is a Python-based web application designed to explore and compare AI tools that work with different types of data, including text, images, audio, and other modalities.

The project provides a simple interface for understanding the capabilities and differences between multimodal AI tools.

## 🎯 Objectives

- Explore different multimodal AI tools.
- Understand how AI tools process different types of input.
- Compare tools based on their capabilities and features.
- Present information through a simple web interface.
- Make multimodal AI technologies easier to understand.

## ✨ Features

- 🧠 **AI Tool Comparison** — Explore and compare multimodal AI tools.
- 🖥️ **Web Interface** — Access the application through a browser.
- 🐍 **Python Backend** — Built using Python.
- 🎨 **HTML and CSS** — Create and style the user interface.
- 📊 **Organized Information** — Present AI tool capabilities in a structured format.

## ⚙️ Installation and Setup

### Prerequisites

- Python installed on your computer.
- Git installed on your computer.
- Visual Studio Code or another code editor.

### 1. Clone the Repository

```bash
git clone https://github.com/sanjanakarthik08-source/multimodal-ai-tools-comparison.git
```

### 2. Open the Project Folder

```bash
cd multimodal-ai-tools-comparison
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

Open the local address displayed in your terminal to access the application.
