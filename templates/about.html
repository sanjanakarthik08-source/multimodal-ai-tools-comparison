PROJECT SUMMARY

About this project

Research question

How well do free multimodal AI tools handle images, documents and audio for study tasks?

Method

Use standardized tasks, identical prompts, six scoring criteria, saved evidence and source verification. Test at least three tools and record unavailable features separately.

Scoring formula

Percentage = (sum of six criterion scores ÷ 30) × 100. Scores are entered by the student and are not independently verified by the app.

Official references

  • OpenAI — File and audio uploads
  • OpenAI — Image inputs
  • Microsoft Copilot — File upload
  • Claude — Upload files
  • Google — NotebookLM Audio Overviews
